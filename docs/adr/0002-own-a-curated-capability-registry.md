# Own a curated capability registry

The executable contract is a typed, compiled-in Go registry that generates direct domain Cobra leaves, machine-readable capability descriptions, Skill references, and coverage tests. QWeather's OpenAPI and documentation are evidence rather than runtime configuration because the upstream spec contains equivalent path templates, wire-format mismatches, and prose-only constraints. The CLI covers all 28 current endpoints, retains the five already-deprecated operations only as non-executable Tombstones, and exposes no arbitrary-path passthrough.
